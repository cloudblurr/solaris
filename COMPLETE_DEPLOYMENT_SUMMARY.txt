================================================================================
                          TROUBLESHOOTING
================================================================================

DNS Not Resolving
  → Check Cloudflare DNS records
  → Verify zone is active
  → Wait for propagation (up to 24 hours)

HTTPS Certificate Issues
  → Verify SSL/TLS mode is "Full"
  → Check certificate validity
  → Wait for issuance (usually instant)

Container Not Responding
  → Check container logs
  → Verify environment variables
  → Check database connectivity
  → Review Cloudflare security rules

High Error Rate
  → Check application logs
  → Verify database connection
  → Review rate limiting settings
  → Check WAF rules

================================================================================
                          QUICK COMMANDS
================================================================================

BUILD LOCALLY
  docker build -t nimbusai:latest .

TEST LOCALLY
  docker-compose -f docker-compose.prod.yml up -d

DEPLOY TO CLOUDFLARE
  ./scripts/deploy-cloudflare.sh

VERIFY DEPLOYMENT
  curl -I https://sol.terragravity.cloud
  nslookup sol.terragravity.cloud

PURGE CACHE
  curl -X POST "https://api.cloudflare.com/client/v4/zones/${CLOUDFLARE_ZONE_ID}/purge_cache" \
    -H "Authorization: Bearer ${CLOUDFLARE_API_TOKEN}" \
    -d '{"purge_everything":true}'

VIEW LOGS
  curl -X GET "https://api.cloudflare.com/client/v4/accounts/${CLOUDFLARE_ACCOUNT_ID}/containers/nimbusai-prod/logs" \
    -H "Authorization: Bearer ${CLOUDFLARE_API_TOKEN}"
